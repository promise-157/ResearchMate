# Branding assets

- `promise-157-logo.jpg` is the repository owner's established rabbit logo, copied from
  `promise-157/Best-README-Template` (`images/userimage.jpg`) only for the GitHub README presentation.
- `researchmate.ico` is the separate, project-specific icon supplied for the ResearchMate Windows
  executable and shortcut. It is intentionally not derived from the GitHub profile logo.

Keep these identities separate: changing the personal GitHub logo must not silently change the
ResearchMate application icon, and changing the application icon must not rewrite the README avatar.
