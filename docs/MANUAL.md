## 1. 简介

ResearchMate 是一个 **AI 辅助论文筛选工具**。

传统看论文的方式：打开期刊网站 → 一篇篇翻标题和摘要 → 点进去看有没有代码 → 判断值不值得精读 → 手动记笔记。一篇论文 5 分钟，翻 50 篇半天就过去了。

ResearchMate 的工作方式：

1. **你导入关注的期刊网址**（arXiv 某个分类、CVPR、NeurIPS 等）
2. **系统帮你爬摘要**（不下载 PDF，省空间，付费墙也挡不住摘要页）
3. **AI 分析每篇摘要**：
   - 有没有开源代码？GitHub 链接是什么？
   - 核心创新点是什么？（一句话）
   - 用了哪些技术/方法？（关键词标签）
4. **AI 批量点评**：这批论文总体趋势是什么？哪些最值得关注？
5. **你扫一眼卡片，感兴趣的加购物车**，最后导出清单集中处理

## 2. 安装

### 环境要求

| 依赖 | 最低版本 | 说明 |
|------|---------|------|
| Python | 3.11+ | 推荐用 conda 管理 |
| Node.js | 18+ | 推荐用 nvm 管理 |
| npm | 9+ | 随 Node.js 附带 |

### 安装步骤

```bash
# 1. 克隆仓库
git clone https://github.com/promise-157/ResearchMate.git
cd ResearchMate

# 2. 创建 Python 虚拟环境（推荐 conda）
conda create -n researchmate python=3.11 -y
conda activate researchmate

# 3. 安装后端依赖（后端开发完成后）
cd src/backend
pip install -r requirements.txt
cd ../..

# 4. 安装前端依赖
cd src/frontend
npm install
cd ../..
```

## 3. 启动

### 方式一：完整启动（后端 + 前端，推荐）

后端开发完成后：
```bash
conda activate researchmate
cd src/backend
python run.py
# 浏览器自动打开 → 看到首页
```

### 方式二：仅前端开发服务器（调试 UI，不需要后端）

```bash
cd src/frontend
npm run dev
# 浏览器打开 http://localhost:5173
```

### 方式三：构建生产版本

```bash
cd src/frontend
npm run build
# 静态文件输出到 dist/ 目录
```

## 4. 页面指南

### 4.1 首页

启动后看到的第一个页面。中间三张导航卡片，底部状态栏。

| 元素 | 说明 |
|------|------|
| 论文中心 | 进入核心功能页（管理期刊源、爬取、查看论文） |
| 全局设置 | 配置 AI 接口、爬取参数、主题外观 |
| 关于 | 查看版本信息和技术栈 |
| 底部状态栏 | 已收录论文数、购物车数量、上次更新时间 |

### 4.2 论文中心

核心页面，从上到下四个区域：

#### 区域一：爬取控制

- **期刊源列表**：你添加的所有期刊网址。每行显示上次爬取时间和新增论文数
- **勾选要爬取的源**：可以选择爬全部或只爬某几个
- **模式选择**：
  - 「仅新论文」（默认）：跳过已爬过的，只抓新出现的
  - 「全部重新爬取」：不跳过，重新爬所有
- **爬取按钮**：点击后显示实时进度（爬取中 → AI 分析中 → 完成）

#### 区域二：AI 本批点评

每次爬取完成后自动生成。显示：
- 本批统计（多少篇、多少有代码）
- 热门研究方向
- 推荐的关注论文
- 技术趋势关键词

#### 区域三：论文列表

每篇论文一张卡片，包含：

| 信息 | 展示方式 |
|------|---------|
| 标题 | 大字加粗 |
| 作者 | 第一作者 et al. |
| 出处 | 期刊名 + 年份 + arXiv ID |
| AI 分析 | 独立背景框 |
| ┣ 代码 | 🔗 绿色（有开源代码）/ 灰色（未发现） |
| ┣ 创新点 | 2 行文字，可展开看全部 |
| ┗ 技术标签 | 3 个彩色标签 + "+N 更多" |

操作：
- ⭐ **收藏**：切换论文的收藏状态
- 🛒 **保存**：加入购物车
- **查看摘要**：弹窗显示完整摘要和 AI 分析
- **访问原文**：在新标签页打开论文链接

筛选栏：
- 搜索框：按标题、作者搜索
- 「有代码」复选框：只看有开源代码的论文
- 「已保存」复选框：只看已加入购物车的
- 排序下拉：最新优先 / 最早优先 / 标题 A-Z

#### 区域四：购物车

点击导航栏右上角购物车图标打开，右侧滑出面板：
- 已保存的论文列表
- 每篇可移除
- 底部「复制标题列表」按钮：一键复制所有标题
- 底部「导出 CSV」按钮：导出为 CSV 文件（后端实现后）

### 4.3 全局设置

左侧导航菜单 + 右侧内容区分成四个标签页：

#### 外观

- **浅色**：默认主题，白色背景
- **深色**：暗色背景，适合长时间阅读
- **跟随系统**：自动跟随操作系统的主题设置
- 选择后立即生效，刷新不丢失

#### AI 配置

| 设置项 | 说明 |
|--------|------|
| API 类型 | OpenAI / Claude / Ollama(本地) / 自定义兼容接口 |
| API Key | 你的 API 密钥，密码框显示，仅本地存储 |
| API Base URL | API 端点地址，使用代理或自定义端点时修改 |
| 模型名称 | 如 `gpt-4o`、`claude-sonnet-5`、`llama3:70b` 等 |
| 测试连接 | 验证配置是否正确（后端实现后生效） |
| Prompt 模板 | 高级选项，可自定义 AI 分析摘要用的提示词 |

#### 爬取设置

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 每次最大论文数 | 50 | 单个期刊源单次爬取上限 |
| 请求间隔 | 2 秒 | 两次请求之间的等待时间 |
| 超时时间 | 30 秒 | 单个请求的超时 |

#### 数据管理

- **数据库位置**：SQLite 文件存放路径（`src/data/researchmate.db`）
- **清空论文数据**：删除所有已爬取的论文（需二次确认）
- **重置所有设置**：恢复设置项为默认值（需二次确认）

### 4.4 关于

显示版本号、项目介绍、技术栈标签和 GitHub 链接。

## 5. 工作流程

### 典型使用流程

```
第一次使用：
  → 全局设置 → 配置 AI API Key
  → 论文中心 → 添加期刊源（粘贴你关注的期刊网址）
  → 勾选期刊源 → 点「开始爬取」
  → 等待爬取 + AI 分析完成
  → 阅读 AI 点评 → 浏览论文卡片
  → 感兴趣的 → 点「保存」加入购物车
  → 全部筛完 → 打开购物车 → 复制标题列表 / 导出 CSV

日常使用：
  → 论文中心 → 勾选要更新的源 → 点「开始爬取」
  → 系统自动只抓新论文（去重已爬过的）
  → 看 AI 点评 → 浏览新增论文
  → 筛选 → 加购物车 → 导出
```

## 6. AI 配置指南

### OpenAI

```
API 类型: OpenAI
API Key:  sk-proj-xxxxxxxxxxxxxxxxxxxx
Base URL: https://api.openai.com/v1
模型:     gpt-4o 或 gpt-4o-mini（省成本）
```

### Claude (Anthropic)

```
API 类型: Claude
API Key:  sk-ant-xxxxxxxxxxxxxxxxxxxx
Base URL: https://api.anthropic.com
模型:     claude-sonnet-5 或 claude-haiku-4-5-20251001（省成本）
```

### Ollama（本地模型，免费）

```
API 类型: Ollama
API Key:  （留空）
Base URL: http://localhost:11434/v1
模型:     llama3.1:8b 或 qwen3:14b
```

前提：已安装 [Ollama](https://ollama.com) 并 `ollama pull llama3.1:8b`

### 代理配置

如果网络访问 OpenAI/Claude 需要代理：

```bash
# 设置环境变量后启动
export HTTP_PROXY=http://127.0.0.1:7890
export HTTPS_PROXY=http://127.0.0.1:7890
python run.py
```

也可以在「AI 配置 → API Base URL」中填写代理地址（如 `https://your-proxy.com/v1`）。

## 7. 常见问题

### Q: 期刊源应该填什么网址？

填你关注的期刊/会议的**论文列表页**。例如：
- `https://arxiv.org/list/cs.AI/recent` — arXiv AI 最新论文
- `https://openaccess.thecvf.com/CVPR2024` — CVPR 2024 论文列表
- `https://proceedings.neurips.cc/paper_files/paper/2024` — NeurIPS 2024

任何能看到论文标题和摘要的页面都可以添加。系统会自动提取。

### Q: 爬取会不会被封 IP？

爬取设置中的「请求间隔」默认 2 秒，已经比较保守。如果担心，可以调到 3-5 秒。单次爬取论文数也可以调低。

### Q: 为什么有的论文显示"未发现开源代码"？

因为该论文的摘要中没有提到 GitHub 链接。AI 只能从摘要文本中识别。如果论文实际有代码但摘要没提，可能会漏掉。这是摘要爬取的固有局限。

### Q: 可以不下载 PDF 吗？

可以，而且默认就是不下载 PDF。ResearchMate 只爬摘要，不碰全文 PDF。节省磁盘空间和带宽。

### Q: 购物车数据存在哪里？

存在本地 SQLite 数据库中。数据不会上传到任何云端服务。如果你清除了数据库，购物车也会清空。

### Q: 如何备份数据？

复制 `src/data/researchmate.db` 文件到安全位置。恢复时复制回来即可。
