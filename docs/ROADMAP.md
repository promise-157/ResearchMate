# 当前路线图

本文是新会话的当前状态入口；只记录已经验证的事实和下一个最小里程碑。

## 已完成：M1 通用文字资料闭环

验收条件：

- [x] 工作区数据库可幂等创建通用资料表，旧论文数据不丢失。
- [x] 用户可导入一段文字并选择/接受资料类型。
- [x] 系统规范化文本、生成内容指纹并阻止精确重复。
- [x] 用户可搜索、按类型/状态筛选和查看资料。
- [x] 用户可修改资料状态，不存在只停留在浏览器的假操作。
- [x] API、存储和前端流程有离线自动测试。
- [x] README 和使用手册与实际行为一致。

## 已完成基础

- Codex 仓库入口、安全边界和产品/架构文档。
- arXiv 公共 API 同步及默认关闭通用 HTML 抓取。
- API Key 非持久化、后端代理和显式论文 AI 附件。
- 工作区导入与路径保护，以及现有核心契约测试。

## 已完成：M2 可审计的通用资料 AI

验收条件：

- [x] 用户从资料详情主动选择分析类型并确认将发送的字段范围。
- [x] 浏览器只调用本机 API，外部模型调用只发生在后端；未配置模型时给出可行动错误。
- [x] 每次运行记录资料 ID、输入哈希、处理器/提示词版本、服务商、模型、状态、结果或错误。
- [x] AI 返回必须经过结构校验，只形成建议和运行记录，不覆盖来源事实或用户确认值。
- [x] 重复输入可识别已有运行，失败不会显示成功，刷新页面后仍可查看历史结果。
- [x] 自动测试使用假模型响应，不使用真实 Key、真实网络或付费调用。
- [x] 支持 2–20 条资料的比较/归纳，明确显示输入清单，每条正文最多发送 3,000 字符。

## 已完成：M3 用户图片与本地 OCR

验收条件：

- [x] 用户可导入 PNG、JPEG 或 WebP 图片，单文件不超过 10 MB。
- [x] 后端校验图片签名，以文件 SHA-256 去重，并将原件保存到工作区关联的本地资产目录。
- [x] 资料详情可安全读取和预览图片，浏览器不接触任意本地路径。
- [x] 用户可主动运行本地 Tesseract OCR；未安装时给出可行动错误，不回退到外部服务。
- [x] OCR 输入哈希、处理器版本、状态、文本结果或错误写入处理历史，刷新后仍可查看。
- [x] 清空或删除工作区时同时删除对应资产；离线测试只使用临时文件和假 OCR。

## M10 之后的建议顺序

以下是当前遗留问题推导出的建议顺序，不是已完成事项，也不是跳过每阶段验收的长期承诺；每完成一个里程碑后都应根据真实使用结果重新核对。

1. **M11 统一论文 AI、资料 AI 与聊天**：把旧论文分析、工作区综述和聊天逐步迁移到通用 provider/audit 边界；聊天只读取明确附加的资料，持久保存多轮消息、资料范围、模型、用量和失败，不依赖浏览器状态制造完成。
2. **M12 OCR 质量与图片完整性**：完成真实 Tesseract/中英文语言包、完整图片解码、像素与解压炸弹防护、预处理和置信度；用同一脱敏样本评估可选 PaddleOCR。默认安装不加入 Paddle、YOLO 或模型权重；YOLO 只有出现明确区域检测数据集和第二真实需求后才评估。
3. **M13 真实公开网络与剩余浏览器验收**：受控验证 arXiv 和一个用户允许的公开页面，并补 M4-V2、M6-V1、M7-V2 的离线浏览器流程；真实网络成功与离线回归证据分开记录。
4. **M14 工作区完整性、显式重新处理与任务恢复**：补隔离资产清理和可移植归档；为来源刷新增加差异预览/接受，并处理进程中断后的 `running` 任务，解决 M3-L1、M5-L1 和 M7-L2。
5. **M15 本地检索扩展**：先用真实数据验证 SQLite FTS、命中片段和排序，再评估可选本地 embedding；外部 embedding 仍须明确展示和确认范围。
6. **后续具名来源**：RSS 或其他公开 API 只有在出现明确用户价值后才立项，每个来源单独完成限制、provenance、失败状态和离线 fixture，不恢复泛化抓取。

真实 Tesseract、DeepSeek 等真实模型服务商、真实网页/arXiv 网络行为始终作为需环境或授权的独立验收项。ResearchMate 不捆绑 Ollama/Paddle/YOLO 或自动下载模型。工程整体完成后再卸载 WSL 用户缓存中的 Playwright Chromium；该缓存不在 Git 仓库内，也不会上传 GitHub。
